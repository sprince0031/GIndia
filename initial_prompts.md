## Prompt 1
Create a comprehensive interactive map of the GI tagged areas of India by states. Make this a single html file with embedded js that allows for the interactivity. Have it be a minimal UX with an off-white background and the state map of India in the forground. There should be 3D and shadow effects that gives an effect of the map floating slightly. Have the map centred and information on the states towards the east show to the right of the page and the west to the right of the page. Place the info cards accordingly. For the interactivity element, by default the page should cycle through the different info cards with a uniform time spent on each card before displaying the next, one at a time. If the user clicks on a state, pause the loop and show the info card of the clicked state and stay at that. In each info card, there should be a heading boldly stating the name of the product with the region. The card should have representative images of the product and the geographical region to the left. Look to find authentic real images instead of generating them. Display a subtle and minimalist floating tool icons from the top left side of the page arranged vertically down for controls like play/pause infocard cycle, categorise products by type, show stats, etc. Research what other useful information this can be organized into and provide the overlays/views that can be toggled from this tool bar. Make it responsive for any screen from a mobile phone to a large display screen (that may be in landscape orientation). Have a narration feature that narrates the info in the info card. This has to run locally and not be an API call. Maintanence cost must be zero. Include all GI products and information given in the table from the following link which also has a map with numbers corresponding to entries in the table. [https://www.taropumps.com/blog/geographical-indication-tags-in-india](https://www.taropumps.com/blog/geographical-indication-tags-in-india). There should be a close "x" button on the top right corner of the info card if the user wants to close and explore other areas of the map, especially to view the map on mobile screens. Include the animation of the state hovering detached from the full map when user hovers or clicks on the state with that state coloured to a teracota accent colour. There should be lines that trace to different spots on the selected state from the info card that is displayed. If there are multiple GI products for a state display them responsively i.e., if on a larger screen, display all at once with them displayed spatially apart from each other. If on a smaller screen display a carousel of the info cards. Double check the images on the cards to make them representative.
